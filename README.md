# Приложение оплаты ХуткiГрош (ЕРИП) для Tilda

Приложение обеспечивает взаимодействие интернет-магазина на базе **Tilda** с платёжным сервисом [ХуткiГрош](https://hutkigrosh.by): выставление счетов в ЕРИП (АИС "Расчет"), оплата картой (WebPay), QR-код, автоматическое обновление статусов заказов после оплаты.

## Поддерживаемые версии

Поддерживаются одновременно две версии приложения:

| | [ХуткiГрош API v3 ERIP](#настройка-hutkigrosh-api-v3) (рекомендуется) | [ХуткiГрош ERIP](#настройка-hutkigrosh-предыдущее-поколение) (предыдущее поколение) |
|---|-----------------------------------------------------------------------|-------------------------------------------------------------------------------------|
| Приложение | `cmsgate-tilda-hutkigrosh-apiv3`                                      | `cmsgate-tilda-hutkigrosh`                                                          |
| API | актуальное поколение (REST API v3)                                    | предыдущее поколение API                                                            |
| Подключение | API-токен, выбор услуги из списка                                     | логин/пароль, ЕРИП ID и код услуги вручную                                          |
| Тестовая система | api-sandbox.hgrosh.by                                                 | trial.hgrosh.by                                                                     |
| Кому подходит | новым магазинам и тем, кто переходит на API v3                        | действующим магазинам, работает как раньше                                          |

> Сервис ХуткiГрош сейчас поддерживает все поколения API параллельно.

Следите за анонсами о сроках отключения старого API и переходите на API v3 заранее (порядок перехода описан в разделе "[Одновременная работа и переход на API v3](#одновременная-работа-и-переход-на-api-v3)").

## Использование

Приложение размещено на рабочем хосте сервиса ХуткiГрош: скачивать и устанавливать в магазин ничего не нужно. Доступ к личным кабинетам приложений (вход по авторизационным данным системы ХуткiГрош, их необходимо получить у менеджеров):

| | ХуткiГрош API v3 ERIP (рекомендуется) | ХуткiГрош ERIP (предыдущее поколение) |
|---|---|---|
| Боевой режим | [cmsgate.esas.by/cmsgate-tilda-hutkigrosh-apiv3/config/login](https://cmsgate.esas.by/cmsgate-tilda-hutkigrosh-apiv3/config/login) | [cmsgate.esas.by/cmsgate-tilda-hutkigrosh/config/login](https://cmsgate.esas.by/cmsgate-tilda-hutkigrosh/config/login) |
| Тестовый режим | [test-cmsgate.esas.by/cmsgate-tilda-hutkigrosh-apiv3/config/login](https://test-cmsgate.esas.by/cmsgate-tilda-hutkigrosh-apiv3/config/login) | [test-cmsgate.esas.by/cmsgate-tilda-hutkigrosh/config/login](https://test-cmsgate.esas.by/cmsgate-tilda-hutkigrosh/config/login) |

## Требования

- Со стороны магазина: сайт на Tilda, для подключения универсальной платёжной системы необходим оплаченный тариф.
- Со стороны приложения: ничего не требуется, приложение размещено и обслуживается на сервере сервиса ХуткiГрош (PHP 5.6 и выше, расширения cURL и PDO).

## Подключение (одинаково для обеих версий приложения)

1. Зайдите в личный кабинет приложения (см. раздел "Использование"), для входа используйте авторизационные данные системы ХуткiГрош (необходимо обратиться к менеджерам для получения авторизационных данных).
1. Настройте приложение (см. "[Настройка ХуткiГрош API v3 ERIP](#настройка-hutkigrosh-api-v3)" или "[Настройка HutkiGrosh (предыдущее поколение)](#настройка-hutkigrosh-предыдущее-поколение)") и скопируйте секрет для подписи заказа (**API Секрет** у API v3, **API Secret** у предыдущего поколения).
1. Подключите платёжную систему в системе администрирования вашего магазина в Tilda (шаги приведены в разделе соответствующего поколения API).
1. Оформите тестовый заказ и убедитесь, что счёт выставляется, а после оплаты статус заказа в Tilda обновляется.

## Настройка ХуткiГрош API v3 ERIP

### Шаг 1. Получите API-токен

В бизнес-аккаунте ХуткiГрош откройте **Настройки > Интеграция ПУ** (раздел доступен ролям "Владелец ПУ" и "Администратор ПУ"). Используйте токен с доступом к информации о ПУ и созданию/редактированию счетов.

### Шаг 2. Подключите магазин

1. На странице "Настройки" приложения вставьте токен в поле **API Токен**.
1. Нажмите кнопку "Обновить", приложение загрузит из ХуткiГрош списки для полей **Услуга**, **Розничная торговая точка**, **Кассовое место**.
1. Выберите значения в списках и нажмите "Сохранить".

### Шаг 3. Остальные параметры

**Основное:**
* **Путь в дереве ЕРИП**: путь, по которому клиент будет искать выставленный счёт (например, `АИС "Расчет" (ЕРИП) > Интернет-магазины/сервисы >`).
* **Срок действия счета (дней)**: как долго счёт будет доступен в ЕРИП для оплаты.

**Экран успешного заказа:**
* **Секция "Инструкция"**: пошаговая инструкция по оплате счёта в ЕРИП.
* **Секция QR-код**: оплата счёта по QR-коду через мобильное приложение банка (QR-код и ссылка на оплату запрашиваются у сервиса).
* **Секция Webpay**: кнопка оплаты счёта картой (переход на WebPay).
* **Текст успешного выставления счета**: может содержать HTML, допустимы переменные `@order_id`, `@order_number`, `@order_total`, `@order_currency`, `@order_fullname`, `@order_phone`, `@order_address`.

**Уведомления** (отправляются шлюзом ХуткiГрош):
* **Email оповещение**: письмо клиенту при успешном выставлении счёта.
* **Sms оповещение**: SMS клиенту при успешном выставлении счёта.

На этой же странице сгенерируйте **API Секрет** (кнопка "Сгенерировать") - он используется для проверки подписи запросов от Tilda.

### Подключение платёжной системы в Tilda

1. В Tilda перейдите: `Настройки сайта > Платёжные системы > Добавить > Внешняя система оплаты` (либо используйте готовый шаблон "Хуткигрош API v3"; полный состав параметров при настройке вручную - см. "[Ручная настройка платёжной системы в Tilda](#ручная-настройка-платёжной-системы-в-tilda)").
1. В поле "URL для оплаты" укажите адрес приложения:

   для боевого режима
   ```
   https://cmsgate.esas.by/cmsgate-tilda-hutkigrosh-apiv3/api/bill/add
   ```
   для тестового режима
   ```
   https://test-cmsgate.esas.by/cmsgate-tilda-hutkigrosh-apiv3/api/bill/add
   ```
1. В поле "Секрет для подписи заказа" вставьте скопированный **API Секрет**.
1. Настройте подпись заказа: алгоритм `sha256`, разделитель `|`, поля подписи `{{order_id}}|{{order_amount}}|{{secret}}|{{order_currency}}`.
1. Укажите "URL страницы успеха" и "URL страницы отказа" - адреса страниц магазина в Tilda, на которые пользователь перенаправляется после успешной оплаты или ошибки.
1. В расширенных настройках (Additional field list) добавьте поля, замапленные на системные поля Tilda: `tilda_success_url`, `tilda_failed_url`, `tilda_notification_url`. Без них приложение не сможет вернуть покупателя в магазин и сообщить Tilda об оплате.

### Ручная настройка платёжной системы в Tilda

Если готовый шаблон не используется, при создании внешней системы оплаты заполните параметры вручную. Ниже - полный состав параметров (значения сверены с кодом приложения и соответствуют настройкам шаблона "Хуткигрош API v3 ERIP").

**Основные настройки:**
* **Заголовок**: произвольное название способа оплаты (например, `Хуткигрош API v3 ERIP`).
* **API URL**: адрес приложения для боевого режима - `https://cmsgate.esas.by/cmsgate-tilda-hutkigrosh-apiv3/api/bill/add`; в поле "Тестовый API URL" - адрес тестового режима `https://test-cmsgate.esas.by/cmsgate-tilda-hutkigrosh-apiv3/api/bill/add`.
* **Логин**: логин в системе ХуткiГрош (необходимо обратиться к менеджерам для получения рабочего или тестового логина); в запросе передаётся полем `ps_hg_login`.
* **Секрет для подписи заказа**: значение **API Секрет**, скопированное в личном кабинете приложения.

**Соответствие полей заказа (маппинг запроса):**
* **Номер заказа**: `order_id` (формат по умолчанию - `<ID проекта>:<ID заказа>`).
* **Сумма заказа**: `order_amount`.
* **Валюта**: `order_currency`.
* **ФИО клиента**: `customer_fio`.
* **Телефон клиента**: `customer_phone`.
* **Email клиента**: `customer_email`.
* **Список товаров**: `order_items` (массив в JSON: название, цена, количество).
* **Подпись**: `signature`.

**Подпись заказа:**
* алгоритм шифрования - `SHA-256`
* тип подписи - особые правила: `{{order_id}}|{{order_amount}}|{{secret}}|{{order_currency}}`
* опции "Верхний регистр", "BASE64 после шифрования", "Добавлять секрет в подпись", "Использовать секрет в качестве ключа алгоритма" должны быть отключены: приложение сверяет подпись с `sha256`-хэшем строки `order_id|order_amount|secret|order_currency`

**Дополнительные поля (Additional field list)** - три поля, замапленные на системные поля Tilda (обязательны для работы приложения):
* `tilda_success_url` - "URL страницы успеха", адрес страницы магазина для возврата клиента после успешной оплаты.
* `tilda_failed_url` - "URL отказа", адрес страницы для возврата при ошибке оплаты.
* `tilda_notification_url` - "URL для уведомлений", системный URL уведомлений Tilda вида `https://forms.tildaapi.biz/payment/custom/psXXXXXXXXX`; по этому адресу приложение подтверждает оплату заказа в Tilda.

### Обязательно: адрес обработчика уведомлений

После оплаты счёта клиентом ХуткiГрош отправляет уведомление в приложение, которое подтверждает оплату заказа в Tilda (на переданный магазином `tilda_notification_url`). Адрес обработчика уведомлений приложения:

* Для боевого режима - ```https://cmsgate.esas.by/cmsgate-tilda-hutkigrosh-apiv3/api/bill/notify```;
* Для тестового режима - ```https://test-cmsgate.esas.by/cmsgate-tilda-hutkigrosh-apiv3/api/bill/notify```;

Адрес настраивается службой технической поддержки ХуткiГрош при подключении услуги, от магазина дополнительных действий не требуется.

### Тестовый режим (Sandbox)

1. Используйте приложение тестового режима (см. раздел "Использование").
1. Получите API-токен тестовой системы (выдаётся при регистрации в ХуткiГрош) и настройте приложение согласно инструкции выше.
1. Счета будут выставляться в тестовую систему `api-sandbox.hgrosh.by`.
1. Проверить выставление счёта можно в личном кабинете приложения на странице "Счета" (кнопка "Тест заказа").
1. Для эмуляции оплаты счёта используйте личный кабинет [cabinet.hgrosh.by](https://cabinet.hgrosh.by) (сверху справа "Профиль пользователя" > "Тестовый режим").

Документация API v3: https://api-dev.hgrosh.by/eripservice/docs/ru/index.html

**Параметры подключения:**

* **Код услуги**: код услуги в дереве ЕРИП, используется при генерации QR-кода.

**Основное:**
* **Путь в дереве ЕРИП**: путь, по которому клиент будет искать выставленный счёт (например, `АИС "Расчет" (ЕРИП) > Интернет-магазины/сервисы >`).
* **Срок действия счета (дней)**: как долго счёт будет доступен в ЕРИП для оплаты.

**Экран успешного заказа:**
* **Секция "Инструкция"**: пошаговая инструкция по оплате счёта в ЕРИП.
* **Секция QR-код**: оплата счёта по QR-коду через мобильное приложение банка (QR-код генерируется приложением на основе кода услуги).
* **Секция Webpay**: кнопка оплаты счёта картой (переход на WebPay).
* **Текст успешного выставления счета**: может содержать HTML, допустимы переменные `@order_id`, `@order_number`, `@order_total`, `@order_currency`, `@order_fullname`, `@order_phone`, `@order_address`.

**Уведомления** (отправляются шлюзом ХуткiГрош):
* **Email оповещение**: письмо клиенту при успешном выставлении счёта.
* **Sms оповещение**: SMS клиенту при успешном выставлении счёта.

Скопируйте **API Secret** и сохраните настройки.

### Подключение платёжной системы в Tilda

1. Включите в профиле Tilda (https://tilda.cc/identity/) настройку "Участвовать в тестировании новых функций" (доступна для оплаченных тарифов).
1. Перейдите в `Настройки сайта > Платежные системы` и выберите пункт `«Универсальная платёжная система»`.
1. Из списка готовых шаблонов выберите `ХуткiГрош (ЕРИП Беларусь)`.
1. Укажите обязательные параметры:
   * **Логин** - логин в системе ХуткiГрош (необходимо обратиться к менеджерам для получения рабочего или тестового логина).
   * **Секрет для подписи заказа** - значение, скопированное из поля **API Secret** личного кабинета приложения.
   * **URL страницы успеха** - адрес страницы, на которую будет перенаправлен пользователь в случае успешной оплаты.
   * **URL страницы отказа** - адрес страницы, на которую будет перенаправлен пользователь, если в процессе оплаты возникнут ошибки.
   * **Тестовый режим** - если отключен, поля логин и секрет для подписи надо брать из реального личного кабинета, иначе из тестового.

### Обязательно: адрес обработчика уведомлений

См. раздел "[Обязательно: адрес обработчика уведомлений](#обязательно-адрес-обработчика-уведомлений)" выше: механизм одинаков для обоих поколений API, отличается только адрес обработчика уведомлений приложения:

* Для боевого режима - ```https://cmsgate.esas.by/cmsgate-tilda-hutkigrosh/api/bill/notify```;
* Для тестового режима - ```https://test-cmsgate.esas.by/cmsgate-tilda-hutkigrosh/api/bill/notify```;

### Тестовый режим

* Используйте приложение тестового режима (см. раздел "Использование") и тестовые логин и секрет.
* Счета выставляются в тестовую систему `trial.hgrosh.by`.
* Для эмуляции оплаты клиентом выставленного счёта воспользуйтесь личным кабинетом тестовой системы [ХуткiГрош](https://trial.hgrosh.by) (меню "Тест оплаты ЕРИП"):
  1. в списке валют выберите вторую BYN
  1. в поле "Введите номер счета для оплаты" укажите номер заказа, показанный на итоговой странице при оплате
  1. нажмите "Проверить счета" и далее "Оплатить"

## Одновременная работа и переход на API v3

* Это два самостоятельных приложения на одном хосте сервиса, у каждого свой личный кабинет и собственные настройки; заказы и данные магазина в Tilda не затрагиваются.
* В Tilda у магазина один способ оплаты: при переходе в настройках платёжной системы меняются URL для оплаты и секрет для подписи заказа.
* Подтверждение оплаты передаётся в Tilda через `tilda_notification_url`, механизм не меняется.

Рекомендуемый порядок перехода:

1. Получите API-токен тестовой системы ХуткiГрош.
1. Настройте приложение API v3 тестового режима и подключите его в Tilda по инструкции выше.
1. Проверьте выставление и оплату счёта в режиме Sandbox.
1. Переключите Tilda на приложение API v3 боевого режима (URL для оплаты и **API Секрет**).
1. Оформите реальный заказ и убедитесь, что статус заказа в Tilda обновился после оплаты.

## Логи

Логи (`cmsgate.log`) ведутся на сервере приложения ХуткiГрош. По вопросам диагностики обращайтесь в службу технической поддержки.

По вопросам подключения и работы сервиса обращайтесь в службу технической поддержки [ХуткiГрош](https://hutkigrosh.by).
